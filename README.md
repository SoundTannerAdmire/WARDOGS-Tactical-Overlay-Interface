## FAQ

<details><summary>Does this bundle all modules from the separate releases?</summary>
Yes. The suite consolidates precision assist, visual overlay, stability module, and raid planner into a single menu. Each module can be toggled independently from the overlay.
</details>

<details><summary>Can I run only the visual overlay without precision assist?</summary>
Every module has its own switch. You can run overlay-only, stability-only, or any combination without loading unused features.
</details>

<details><summary>How much memory does the injected module use?</summary>
The injected component consumes roughly 4 MB of process memory. It does not write to disk after injection and leaves no files in the WARDOGS directory.
</details>

<details><summary>Will my skins or Steam inventory be affected?</summary>
The suite does not modify your Steam inventory, skins, or profile. It operates within the game process only and has no access to Steam account data.
</details>
